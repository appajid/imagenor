# Imagenor 0.1.0-alpha.1

First Imagenor alpha preview, derived from PhotoCraft baseline `14a4ab9b3f38f0b68fde6add97384919710374c8` with local changes. This version starts Imagenor's own version sequence; it is not PhotoCraft 0.15.1 or a stable Photoshop replacement.

Included:
- Imagenor branding and native `.ignr` documents, retaining inherited archive compatibility.
- English interface, with Indian-language editable document-text work and 15-sample persistence regressions. Full Indic IME/caret coverage is not yet established.
- Licensed unchanged sRGB2014, GRACoL2013 CRPC6 and SWOP2013 C3 CRPC5 profiles, with sources/hashes and licences.
- Authorised ASE spot-library imports; Lab alternate preservation through native and PSD/PSB save/reopen.
- 16-bit individual spot-coverage TIFF export through `file.exportSpotPlate`.
- Reviewed upstream fixes #9076 (Average transparency), #12260 (Lab/8 replacement lightness), #12381 (picked-CMYK eraser matching).

Validation from the local development batch: 147 paint/related engine tests, strict Clippy, WASM24+HEIF, layering and command-safety sweep passed. An earlier 309-file independent PSD corpus gate retained its existing floor:249 reference matches,56 differences,4 skips,zero crashes. This is not a full-CI pass.

Known limits:
- Full workspace tests have previously observed failures involving deep engine/native-format/SVG stacks and inherited UI expectations. This preview is not production-ready; use copies of documents.
- Official Pantone libraries are not bundled. Authorised imports only; no Pantone certification.
- CMYK process-plate sets, trapping, halftoning, overprint and measured press/RIP validation remain incomplete.
- Matching an arbitrary monitor to paper is not guaranteed; correct calibrated monitor/printer/ink/paper profiles remain necessary.
- The first locally produced desktop artifact targets Apple silicon macOS. Intel macOS, Windows, Linux and browser packages are not claimed tested or published by this release.
- macOS preview builds are ad-hoc signed and not notarized; Gatekeeper may block them. No Apple Developer signing identity is assumed.
- No additional document fonts are bundled for Indian scripts; installed suitable fonts are required. The English interface is intentional.
- In-app automatic update transport is disabled.

Inherited upstream workflow templates are preserved under `.github/upstream-workflows/` as references, not active workflows. The manual full-quality workflow is self-contained and does not depend on the upstream organisation's reusable workflows. Automatic publication is not enabled.

Source licences: MIT OR Apache-2.0, preserving upstream notices. Bundled profiles/fonts/icons retain their own terms. Supplied Imagenor branding is authorised for this owner's private repository/release hosting by the publication request; ownership and public redistribution/relicensing remain undeclared.
