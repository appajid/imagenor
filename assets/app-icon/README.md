# Imagenor app icon

The owner-supplied purple/pink Imagenor mark on a dark rounded tile is the master in `imagenor.svg` (512 × 512). `imagenor-small.svg` is the same supplied artwork. Platform PNG, ICO and ICNS outputs derive from this SVG. macOS uses a transparent margin; Linux and Windows use the complete tile without cropping. Regenerate with `packaging/icons.sh` and resvg. Source variants are retained in `assets/brand`. See LICENSE.txt and ATTRIBUTION.md for the local-only asset rights status.
